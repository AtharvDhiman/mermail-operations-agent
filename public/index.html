VERIFIED PROTOCOL STATE MACHINE

The 7-Step Autonomous DApp Lifecycle

Engineered for verified execution in decentralized environments. Every inbound message traverses a strict, verified state machine before any external action or on-chain transfer occurs.

STEP 01

Inbound Ingestion

Polls Mermail MCP inbox or receives webhook events, normalizing sender headers, message timestamps, and payload attributes.

STEP 02

Thread & Context Stitching

Resolves conversation threads, extracts historical commitments, participant identities, and flags contradictory statements.

STEP 03

Deterministic Triage

Evaluates intent across 4 operational modes, assigning priority (P0–P4), urgency tier, and calculating a 0–100% confidence metric.

STEP 04

Dynamic DAG Planning

Generates a verified execution plan where read-only steps run first, and irreversible or high-risk actions are queued safely.

STEP 05

Safety & Prompt Sanitization

Scans body text for prompt injection patterns, validates blockchain addresses against allowlists, and enforces daily spend caps.

STEP 06

Dual-Control Approval

High-risk actions pause execution, generating a cryptographic token (APPR-*) requiring an authenticated human operator to authorize.

STEP 07

Self-Cancelling Follow-Ups

Registers Day 2/Day 5 persistent check-in reminders that automatically cancel the instant the external party responds to the thread.
